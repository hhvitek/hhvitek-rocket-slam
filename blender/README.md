# Blender

All models are **generated by Python scripts** — never edit `.fbx` or `.blend` by hand;
change the script and regenerate.

| Folder | What | In git |
|---|---|---|
| `scripts/` | `bpy` generators (`common.py`, `palette.py`, `booster.py`, `landing_pad.py`, `droneship.py`, …) | yes |
| `blend/` | `.blend` file saved by each generator, for inspecting the model in Blender | yes (small, low-poly) |
| `renders/` | preview PNG of each model (shape, scale, axes check) | yes |

Outputs for the game go straight to `../unity/Assets/Models/` (FBX) and `../unity/Assets/Textures/`
(palette atlas).

Run a generator headless:

```bash
blender -b --factory-startup --python blender/scripts/booster.py
```

Conventions: 1 unit = 1 m, FBX export with axes set for Unity (forward −Z, up Y), apply transforms.
